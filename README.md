# 📊 Adventure Works Sales Analysis Dashboard | Excel

## 📌 Project Overview
Developed an interactive sales analysis dashboard using Microsoft Excel to evaluate business performance and generate meaningful insights through data analysis and visualization.

## 📈 Key Metrics
- **Total Revenue:** $307.09M
- **Total Profit:** $126.29M
- **Total COGS:** $180.80M
- **Total Quantity:** 631.92K
- **Total Transactions:** 60.40K
- **Profit Margin:** 41.1%

## 📊 Analysis Highlights
- Year-wise performance.
- Monthly profit trends.
- Quarterly profit analysis.
- Weekday vs. weekend performance.
- Day-wise profit analysis.
- Country-wise analysis.
- Interactive filters and slicers.

## 💡 Key Business Insights
- Q2 generated the highest quarterly profit at **$39.02M**.
- Weekdays contributed **72% of total profit**.
- Thursday recorded the highest profit among the highlighted weekdays at **$18.81M**.
- Interactive dashboards help analyze business performance across multiple dimensions.

## 🛠️ Tools & Skills Used
Microsoft Excel | Data Cleaning | Excel Formulas | PivotTables | PivotCharts | Slicers | Data Visualization | Dashboard Design | Business Insights
